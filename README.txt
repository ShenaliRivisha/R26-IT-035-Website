HOW TO RUN:
  Simply double-click index.html — all documents link
  directly to Google Drive, no server needed.

HOW TO ADD NEW DOCUMENTS (PP2, PP3, Final, Research Paper):
  1. Upload file to Google Drive
  2. Right-click → Share → "Anyone with the link" → Copy link
  3. Open index.html in VS Code or Notepad
  4. Search for the tab (e.g. "tab-pp2")
  5. Replace placeholder_card(...) with doc_card using your link

HOW TO DEPLOY FREE:
  Netlify: drag & drop this folder at netlify.com
  GitHub Pages: push index.html to a repo, enable Pages
